# American Dialects
Example usage of the speech recognition service to transcribe audio samples from the Dictionary of [American Regional English](https://dare.wisc.edu/audio/).

To run this example:

1. Download the audio samples: `./download.sh`
2. Launch the transcription service (assuming Blackfish is already be running): `./launch.sh`
3. Run the script: `python american-dialects.py`

**Note** - This is example assumes that Blackfish is running on a remote cluster.
